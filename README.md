==================================================
  Do Not Touch Face
  손이 얼굴에 닿는 횟수를 자동으로 카운트합니다.
==================================================


[ 설치 ]

  python -m pip install -r requirements.txt


[ 실행 ]

  python counter.py


[ 동작 방식 ]

  - 카메라 창이 뜨고 얼굴과 손을 실시간으로 감지합니다.
  - 손이 얼굴 영역에 닿는 순간 카운트가 올라갑니다.
  - 닿고 있는 동안은 카운트 안 됩니다 (떼었다가 다시 닿아야 +1)
  - 종료 시 터미널에 총 횟수가 출력됩니다.


[ 종료 ]

  Q 키
